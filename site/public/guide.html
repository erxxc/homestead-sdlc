Geiger Capital

Getting Started

Join the active All of Create world, or review the retained alternate releases.

Active primary world

Install All of Create version 2.6 in CurseForge, allocate at least 6 GB of memory, and join mc.geigercapital.us. The server runs Minecraft 1.21.1 on NeoForge.

View live status and pack details

All of Create Requirements

Minecraft Java Edition1.21.1
LauncherCurseForge App
RAM allocated6 GB minimum, 8 GB recommended
Modpack versionAll of Create 2.6

Installation

1
Install CurseForge
Download the CurseForge app, open Minecraft, and sign in with the Microsoft account that owns Java Edition.
2
Find All of Create
Search Minecraft modpacks for “All of Create” and install release 2.6. Confirm the profile shows Minecraft 1.21.1 before launching.
3
Allocate memory
Open Profile Options and set memory to at least 6144 MB. Use 8192 MB when the computer has enough free RAM.
4
Add the server
Launch the pack, open Multiplayer, choose Add Server, and enter the address below.

Server Address

mc.geigercapital.us
